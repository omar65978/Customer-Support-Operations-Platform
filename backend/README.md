# Legacy backend (not used)

This folder holds an earlier json-server prototype (`server.js`, `db.json`, `api/`, `vercel.json`). Neither application uses it. Both apps talk to Supabase directly (see the root README).

It is kept only for reference. It contains password hashes for demo accounts from that prototype. Do not deploy it. If you no longer need it, delete the folder; nothing else depends on it.
